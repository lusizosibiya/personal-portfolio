Lusizo Sibiya — Personal Portfolio

A responsive personal portfolio website showcasing my journey as an aspiring software developer and self-taught graphic designer.

The portfolio was built with React and Tailwind CSS and is designed to present my skills, projects, experience, and contact information in a clean, creative, and responsive way.

*Features*
- Fully responsive layout for desktop, tablet, and mobile
- Light and dark mode
- Sticky responsive navigation bar
- Mobile hamburger navigation
- Custom hero section with layered typography, avatar artwork, and SVG divider
- Downloadable CV
- About Me section
- Skills section
- Responsive projects carousel
- Individual, group, and real-world project showcases
- Live project and GitHub repository links
- Responsive contact section
- Contact form powered by Web3Forms
- GitHub, LinkedIn, and email contact links
- Smooth scrolling between sections
- Responsive footer aligned with the navbar layout

*Built With*
- React
- JavaScript
- Tailwind CSS
- HTML

*Responsive Design*
A major focus of this version of the portfolio was improving responsiveness throughout the site.
Updates included:
- Rebuilding the navbar for desktop and mobile layouts
- Adding a responsive hamburger menu
- Making the navigation sticky
- Reworking the hero layout to avoid fixed-position issues
- Replacing large background images with CSS backgrounds and reusable SVG dividers
- Making avatar artwork scale and stay correctly positioned using responsive sizing
- Rebuilding the projects section as a horizontal carousel
- Removing unnecessary fixed section heights
- Improving the contact layout for smaller screens
- Aligning the footer with the navbar spacing
- Improving dark mode consistency across sections

*Dark Mode*
The site includes a custom dark mode toggle. Dark mode styling is applied across the navigation, hero, project cards, contact section, and footer.

*Running the Project Locally*
Clone the repository:
- git clone https://github.com/lusizosibiya/personal-portfolio.git
- Move into the project folder:
- cd personal-portfolio
- Install dependencies:
- npm install
- Start the development server:
- npm run dev
